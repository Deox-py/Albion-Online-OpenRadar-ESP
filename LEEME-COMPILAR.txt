OpenRadar 2.3ESP_Deox - AutoBuild V2

FORMA FACIL
===========

1. Extrae TODO el ZIP a una carpeta normal.
2. Doble clic en:

   COMPILAR-PORTABLE.bat

3. Espera.
4. Si todos los tests pasan, se abrira la carpeta:

   dist\

5. El resultado sera un EXE REAL compilado del source 2.3ESP_Deox:

   dist\OpenRadar-2.3ESP_Deox.exe

CAMBIO IMPORTANTE EN V2
=======================

Ya NO necesitas winget para MSYS2/MinGW.

Si no tienes C:\msys64, el script:
- descarga el SFX oficial desde repo.msys2.org;
- verifica su firma Authenticode;
- lo extrae de forma local dentro de .build\;
- instala MinGW-w64 GCC con pacman;
- usa ese GCC solamente para compilar el proyecto.

No modifica tu PATH permanente ni instala MSYS2 globalmente.

TU PC YA TIENE
==============
Según la salida que enviaste:
- Go 1.27.1: OK
- Node 24.20.0: OK

Por eso el error anterior de winget queda solucionado con esta version.

NPCAP
=====
El script descarga solamente el SDK publico de Npcap para compilar.
Para ejecutar la captura necesitas Npcap Runtime instalado. Si el OpenRadar
original ya captura paquetes en tu PC, ya lo tienes.

QA
==
Antes del EXE ejecuta:
- npm ci
- tests frontend
- typecheck
- lint
- tests Go
- build de assets
- go build Windows amd64

Si falla, revisa build-logs\ y pasa el log para corregirlo.

PORTABLE FINAL
==============
El EXE final usa los assets embebidos de embed_prod.go y guarda sus datos
en %%LOCALAPPDATA%%\OpenRadar-2.3ESP_Deox\. Para compartir la aplicacion
no hace falta enviar el source ni las dependencias de compilacion.


V4 - PORTABLE + NPCAP
=====================
El EXE final ahora se construye en dos etapas:

1. OpenRadar-core.exe
   - nucleo real del radar
   - frontend/assets embebidos
   - captura Npcap mediante CGO

2. OpenRadar-2.3ESP_Deox.exe
   - launcher portable sin dependencia de wpcap.dll al arrancar
   - contiene el nucleo anterior embebido
   - es el UNICO archivo que debes compartir

En un PC sin Npcap:
- muestra una ventana preguntando si desea instalarlo;
- si acepta, descarga Npcap 1.89 directamente desde npcap.com;
- verifica la firma Authenticode;
- abre el instalador de forma visible;
- cuando Npcap esta disponible, inicia OpenRadar.

Npcap no se redistribuye dentro del EXE.

Tambien se corrigieron los 8 fallos detectados por el QA anterior:
- contratos de traduccion ES actualizados;
- pluralizacion "interfaces";
- aria-label traducido;
- bug real de SettingsSync al eliminar opciones entre pestanas.
